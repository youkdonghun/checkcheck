체크체크 v0.3.0은 선택한 문장을 작은 창에서 빠르게 검토하도록 사용 흐름을 개선했습니다.

- 별도 간단 규칙 모드를 제거하고 로컬 AI를 기본으로 통일했습니다.
- 앱 시작 때 설치된 모델을 미리 불러오고, 같은 글·모드의 최근 결과를 메모리에서 재사용합니다. 외장 GPU 선택과 프롬프트 재사용도 개선했습니다.
- 우클릭 시 선택 영역을 미리 읽지 못해도 마우스 근처에 검사 버튼을 표시합니다. 클릭하면 글을 가져오고, 지원하지 않는 앱에서는 작은 창에 붙여넣어 검사할 수 있습니다.
- 단축키 변경·동일 조합 재등록·중복 실행·설정 중 실행 문제를 수정했습니다.
- 작은 창에 붙여넣기, 경과 시간, 중지 버튼과 네이버 검사기 바로가기를 추가했습니다.
- 기존 앱의 ‘최신 버전 확인’에서 업데이트하거나 아래 CheckCheck.exe를 받으세요. 설치된 모델과 설정은 유지됩니다.

네이버 공식 공개 API 목록에서 일반 개발자가 발급받을 수 있는 문장 맞춤법 검사 API를 확인하지 못했습니다. 네이버 버튼은 원문을 복사하고 웹 검사기를 여는 기능이며, API 연동은 아닙니다. [공식 API 목록](https://developers.naver.com/products/intro/plan/plan.md)

검증 PC(RTX 3050 Ti)에서 준비된 AI의 짧은 예문 검사는 약 0.60~1.55초, 같은 글 재검사는 0.01초 미만이었습니다. 처음 메모리에 불러오는 데는 약 11~16초가 필요하고, 긴 글이나 다른 PC에서는 더 오래 걸립니다. 교정 제안은 원문과 비교한 뒤 선택해 주세요.

검증: 핵심 검사 1,776개, 화면·단축키 회귀 검사, 트레이·중복 실행 12개, 업데이트 파일 교체·재시작 검사를 통과했습니다. 실제 외부 앱을 사용하는 우클릭 입력 검사는 Windows가 테스트 창의 포커스를 허용하지 않아 완료하지 못했습니다. 모든 앱과의 호환성이 확인된 것은 아니며, 선택 읽기를 지원하지 않는 앱에서는 붙여넣기를 사용하세요.
