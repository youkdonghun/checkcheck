# 체크체크 v0.2.0

로컬 AI를 기본으로 사용하며 첫 실행 때 무료 모델을 자동으로 다운로드합니다. 기존 기본 검사는 등록된 오탈자만 확인하는 보조 기능으로 명확하게 표시합니다.

- X를 눌러도 트레이에서 다운로드·단축키 유지, 명시적 종료 및 중복 실행 방지
- 단축키 직접 변경, 충돌 시 기존 등록 유지
- 작은 검토 창, 드래그 후 우클릭 시 선택 영역 교정 팝업, 기능 켜기/끄기
- 수정 항목 선택·복사·검증 가능한 입력칸에 반영
- 한글을 유니코드 이스케이프 문자열로 모델에 전달하던 문제 수정, 로컬 규칙으로 철자 보완
- GitHub 최신 버전 확인, 다운로드 크기·해시·버전 검증, EXE 교체 및 재실행
- EXE, ZIP, SHA256SUMS.txt 릴리스 자산과 빌드 자동화

처음 다운로드는 약 2.4GB입니다. 바른 API는 선택 기능이며 로컬 AI에는 API 키·사용료가 없습니다.

우클릭 팝업은 선택 영역을 접근성 API로 읽을 수 있는 앱에서 지원합니다. 직접 문서 수정은 일반 Win32 Edit 입력칸만 지원하고, 한글·Word·브라우저에서는 복사를 이용하세요. AI 수정안은 사용자가 확인해야 하며 모든 문법 오류를 찾아내지는 못합니다.

업데이트 설치 전 필요한 글을 복사하세요. 모델·설정은 유지하지만 열려 있는 글과 수정안은 복원하지 않습니다.
