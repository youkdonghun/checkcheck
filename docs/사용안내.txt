체크체크 0.3.0 · Windows 10/11 64비트

시작하기
1. 체크체크.exe 또는 CheckCheck.exe를 실행합니다.
2. 처음 한 번 무료 로컬 AI 모델 약 2.4GB를 자동으로 내려받습니다.
   진행률을 확인하거나 준비 중지를 누를 수 있습니다. 다시 시작하면 이어받습니다.
   X를 누르면 창만 숨겨지고 다운로드는 계속됩니다.
3. 설치한 모델은 앱을 켤 때 미리 메모리에 불러옵니다. ‘로컬 AI · 준비됨’이면 바로 검사할 수 있습니다.
   준비 중에도 글을 입력할 수 있습니다. 글을 입력하고 검사하기(Ctrl+Enter)를 누릅니다.
4. 수정 제안을 확인해 바꾸기·넘기기 또는 모두 선택을 누릅니다.
5. 선택한 수정문을 복사해 원래 문서에 붙여넣습니다.

빠르게 쓰기
- 다른 앱에서 글을 선택하고 Ctrl+Alt+Space를 누르면 작은 창으로 가져와 검사합니다.
- ‘단축키 · 편의 설정’에서 원하는 단축키와 작은 창 사용 여부를 바꿀 수 있습니다.
- ‘작은 창으로 열기’는 직접 입력한 글도 작은 창에서 확인합니다.
- 작은 창의 체크박스를 선택한 항목만 복사·반영합니다. 크게 보기로 전체 화면에 돌아갑니다.
- 검사 진행 상태와 경과 시간을 확인할 수 있으며, 중지 버튼으로 검사를 취소할 수 있습니다.
- 다른 일반 앱·사이트에서 우클릭하면 마우스 근처에 작은 검사 버튼이 뜹니다.
  글을 선택한 뒤 이 버튼을 클릭하면 선택한 글을 작은 창으로 가져와 검사합니다.
  선택 영역을 미리 읽지 못해도 버튼은 표시됩니다. 원래 앱의 우클릭 메뉴는 유지됩니다.
  검사 버튼은 사용하지 않으면 약 8초 뒤 닫힙니다. 원하지 않으면 편의 설정에서 끄세요.
- 글을 가져오지 못하는 앱에서는 선택한 글을 직접 복사한 뒤 작은 창에 붙여넣으세요.
  우클릭 검사에서 선택 영역이 없다고 문서 전체를 가져오지는 않습니다.
- 단축키 설정 중에는 가져오기 단축키의 실행을 잠시 멈춥니다.
  Ctrl 또는 Alt를 포함한 문자·숫자·F키·Space 조합을 쓰세요. 다른 앱과 충돌하면 기존 설정을 유지합니다.

백그라운드 실행
- 큰 창·작은 창의 X는 화면을 닫습니다. 체크체크는 트레이에서 계속 실행됩니다.
- 트레이 아이콘을 두 번 누르면 큰 창을 다시 엽니다.
- 트레이 우클릭 → 체크체크 종료를 눌러야 완전히 종료됩니다.
- EXE를 다시 실행해도 중복 실행하지 않고 기존 창을 보여줍니다.

자동 업데이트
- 앱 실행 시 GitHub 릴리스의 최신 버전을 확인합니다.
- ‘최신 버전 확인’에서 새 버전 다운로드와 설치를 시작할 수 있습니다.
- 열려 있는 글과 수정안은 복원되지 않으니 필요한 내용을 먼저 복사하세요.
- 파일 크기·SHA-256·버전을 검증한 뒤 앱을 종료하고 EXE를 교체·재실행합니다.
- 교체 실패 시 이전 EXE를 복구합니다. 바로 전 버전은 EXE 옆 .previous 파일로 남습니다.
- 다운로드한 AI 모델과 편의 설정은 그대로 유지합니다.
- 실행 파일 폴더에 쓰기 권한이 없으면 GitHub에서 새 EXE를 직접 받아 사용하세요.

검사 엔진
- 로컬 AI(기본): Qwen3 4B가 이 PC에서 한글·영문 문장을 검사합니다.
  API 키나 사용료가 없으며, 글은 외부로 전송하지 않습니다. 한 번에 3,000자까지 지원합니다.
  별도 ‘간단 규칙’ 모드를 제거했습니다. 기존에 그 모드를 썼다면 로컬 AI로 전환됩니다.
  같은 글을 같은 모드로 다시 검사하면 메모리에 남아 있는 최근 결과를 재사용합니다.
- 바른 API(선택): 한국어 맞춤법·띄어쓰기를 api.bareun.ai 서버에 전송해 검사합니다.
  https://bareun.ai/product 에서 본인 API 키를 발급받아 API 설정에 입력하세요.
  무료 한도는 제공자에서 확인하세요. 앱은 유료 전환·결제하지 않습니다.
  키는 현재 Windows 계정용으로 암호화합니다. 키를 비우고 저장하면 지워집니다.

검사 속도
- 모델 다운로드가 끝나도 처음 메모리에 불러오는 시간이 필요합니다. 앱 실행 때 미리 준비합니다.
- 검증 PC(RTX 3050 Ti)에서 첫 메모리 준비 약 11~16초, 준비 후 짧은 예문 약 0.60~1.55초,
  540자 글은 약 7.6초가 걸렸습니다. 모든 PC나 문장에서 같은 속도를 보장하지 않습니다.
- 글 길이·내용·PC 사양에 따라 달라지며 CPU만 사용하는 PC에서는 더 느릴 수 있습니다.

네이버 웹 검사기
- ‘네이버 검사기 ↗’를 누르면 원문을 복사하고 네이버 웹 검사기를 엽니다.
  열린 검사기에 Ctrl+V로 붙여넣어 사용하세요. 버튼을 누르는 것만으로 원문을 전송하지 않습니다.
- 네이버 공식 공개 API 목록에는 문장 맞춤법 검사 API가 없습니다.
  일반 개발자가 발급받을 수 있는 맞춤법용 API 키를 확인하지 못해 웹 바로가기를 제공합니다.
  검색어 오타 변환 API는 문장 교정과 다른 기능입니다. 이 버튼은 API 연동이 아닙니다.
- 공식 API 목록: https://developers.naver.com/products/intro/plan/plan.md

적용 범위
- 직접 반영은 검증한 Win32 일반 Edit 입력칸만 지원합니다.
- 한글·Word·브라우저·서식 편집기는 복사해서 붙여넣으세요.
- 원문이나 선택 범위가 바뀌면 직접 반영하지 않습니다. 다시 가져와 검사하세요.
- 우클릭 버튼 표시와 선택 영역 읽기는 별개입니다. 앱에 따라 선택한 글을 읽지 못할 수 있습니다.
  관리자 권한 앱·UAC 보안 화면 등에서는 Windows 권한 제한이 적용됩니다.
- 제안이 없다고 오류가 없다는 뜻은 아닙니다. AI는 오류를 놓치거나 잘못 바꿀 수 있습니다.
- 숫자·날짜·URL 일부 보존 검사를 하지만 의미 보존을 보장하지 않습니다.
- 이름·회사명은 보호할 단어 관리에 등록하고, 수정 전후 내용을 검토하세요.

저장 위치
- 설정: %LOCALAPPDATA%\CheckCheck\settings.json
- AI 모델: %LOCALAPPDATA%\CheckCheck\Models
- 실행 도구: %LOCALAPPDATA%\CheckCheck\Runtime
- 업데이트: %LOCALAPPDATA%\CheckCheck\Updates
- 문서 원문과 검사 이력은 디스크에 저장하지 않습니다.
- 최근 결과는 앱 실행 중 메모리에만 보관하며, 앱을 완전히 종료하면 사라집니다.
