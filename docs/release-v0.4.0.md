체크체크 v0.4.0은 우클릭 메뉴와 교정 화면을 다시 구성하고, 긴 글의 최소 교정에서 수정이 필요한 문장만 반환하도록 검사 방식을 바꿨습니다.

- **우클릭 메뉴 확장**: ‘최소 교정’, ‘자연스럽게’, ‘업무용’ 중 선택하거나 ‘복사한 글 검사’를 누를 수 있습니다. 원래 앱의 우클릭 메뉴는 유지됩니다. 선택한 글은 검사 명령을 누를 때 가져오며, 평소 마우스 클릭마다 문서를 읽지 않습니다.
- **더 크고 읽기 편한 검토 창**: 기본 680×740, 최소 520×520 크기로 조절할 수 있습니다. 원문 접기, 창 고정, 수정 제안·전체 결과 탭을 제공합니다. 검토 창은 자동으로 사라지지 않습니다.
- **문맥 안에서 수정 전후 비교**: 카드에 주변 문맥과 수정 전·후를 함께 표시합니다. 공백·줄바꿈만 바뀌는 부분도 기호로 구분합니다. 채택·넘기기·모두 채택·모두 해제·되돌리기를 지원하며, 채택한 수정만 복사·반영합니다.
- **긴 글의 부분 결과 표시**: 최소 교정에서 240자를 넘는 글은 AI가 모든 문장을 확인해 오류 문장을 먼저 찾고, 해당 문장만 교정합니다. 짧은 선택 영역은 바로 교정합니다. 완료된 구간의 제안부터 검토할 수 있고, 이후 결과가 도착해도 기존 선택을 유지합니다. 한 번에 10,000자까지 검사할 수 있습니다. 자연스럽게·업무용 말투는 전체 문장을 다시 다듬는 방식입니다.
- **중지·입력 보호**: 검사 중에도 경과 시간 확인과 중지가 가능합니다. 중지하거나 오류가 난 검사는 완료된 구간의 제안만 남기며, 전체 검사가 완료되기 전에는 수정문 복사·직접 반영을 막습니다. 글을 가져오는 동안 사용자가 새로 입력한 내용은 늦게 도착한 캡처로 덮어쓰지 않습니다.
- **네이버 바로가기 제거**: 네이버 웹 검사기 링크를 앱에서 제거했습니다. 네이버 맞춤법 API 연동은 제공하지 않습니다.
- **업데이트 설치 안정화**: PowerShell 실행 환경에 따라 파일 검증 명령을 찾지 못하던 문제를 고쳤습니다. .NET SHA-256으로 다운로드 파일을 검증하고, 잘못된 파일은 기존 실행 파일을 변경하지 않고 거부합니다.

검사 시간에는 모델 메모리 준비·다운로드·원래 앱의 선택 영역 가져오기 시간을 포함하지 않습니다. 두 검사 모두 수정 제안은 0개였으며, 첫 구간 결과는 첫 수정 제안을 뜻하지 않습니다. 기존 v0.3의 같은 2,152자 글은 별도 Core 엔진 측정에서 37.05초·39.53초가 걸렸습니다. 이전 수치는 WPF 화면 경로의 측정이 아닙니다. 글의 내용·검사 모드·하드웨어에 따라 시간은 달라지며, CPU만 사용하는 PC에서는 더 느릴 수 있습니다. 교정 품질에는 한계가 있습니다. 긴 글에서 처음 오류 문장을 찾는 단계가 놓친 문장은 이후 교정 단계에 전달되지 않습니다. 네이버 D2 글에 오류 6개를 넣은 검사에서는 3개를 교정하고 3개를 놓쳤습니다. ‘잇습니다’, ‘빠르구’, ‘나타낫습니다’는 남았습니다. 이 결과는 제한된 예문의 확인 결과이며 일반적인 정확도 수치가 아닙니다. 제안이 없다고 글에 오류가 없다는 뜻은 아니며, 채택하기 전에 의미와 사실을 확인하세요.

오류를 넣은 2,152자 글은 별도 Core 엔진 측정에서 6.75초·5.91초가 걸렸습니다. 위 표의 원문 검사와 입력·측정 경로가 다르며, 결과는 동일하게 오류 6개 중 3개 교정이었습니다.

핵심 자동 검사 1,806개, 배포 EXE의 WPF 화면·단축키 검사, 트레이 생명주기 12개 검사, 업데이트 교체·백업·재실행 및 잘못된 해시 거부 검사를 통과했습니다. 우클릭 메뉴 표시와 원문 가져오기는 별개의 기능입니다. 모든 외부 앱과의 호환성이 확인된 것은 아니며, 선택 영역을 읽지 못하는 앱에서는 글을 복사한 뒤 ‘복사한 글 검사’를 이용하세요. 직접 반영은 지원되는 일반 입력칸에서만 가능하며 한글·Word·브라우저 문서는 수정문을 복사해 사용하세요.
