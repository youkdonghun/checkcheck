# 체크체크

Windows에서 한글·영문 문장을 교정하고, 바뀌는 부분을 확인한 뒤 원하는 수정만 반영하는 무료 데스크톱 앱입니다.

## 다운로드

**[Windows EXE 다운로드](https://github.com/youkdonghun/checkcheck/releases/latest/download/CheckCheck.exe)** · **[사용안내 포함 ZIP](https://github.com/youkdonghun/checkcheck/releases/latest/download/CheckCheck-win-x64.zip)** · [릴리스 목록](https://github.com/youkdonghun/checkcheck/releases)

Windows 10/11 x64용입니다. .NET은 별도 설치하지 않아도 됩니다. 처음 실행하면 무료 로컬 AI 모델(Qwen3 4B, 약 2.4GB)과 실행 도구를 자동으로 다운로드합니다. 진행률 확인·중지·이어받기를 지원합니다. X를 눌러도 트레이에서 다운로드와 단축키가 유지됩니다. 완전히 종료하려면 트레이 아이콘을 우클릭해 **체크체크 종료**를 누르세요.

## v0.4.0

- **우클릭 메뉴에서 바로 선택**: 다른 일반 앱·사이트에서 우클릭하면 선택한 글을 ‘최소 교정’, ‘자연스럽게’, ‘업무용’으로 검사할 수 있는 메뉴가 뜹니다. ‘복사한 글 검사’로 클립보드의 글도 검사할 수 있습니다. 원래 앱의 우클릭 메뉴는 유지됩니다.
- **읽기 편한 검토 창**: 기본 680×740 크기의 창을 자유롭게 조절할 수 있습니다. 원문을 접어 수정 목록을 넓게 보고, 수정 전·후와 주변 문맥을 카드에서 확인하세요. 선택한 수정이 적용된 전체 글은 별도 탭에서 확인할 수 있습니다.
- **수정 하나씩 검토**: 채택·넘기기·모두 채택·모두 해제·되돌리기를 지원합니다. ‘전체 결과’ 탭에서 채택한 수정만 반영한 글을 확인할 수 있습니다. 검토 창은 자동으로 사라지지 않으며, 고정하면 다른 창 위에서도 볼 수 있습니다.
- **긴 글 검사 개선**: 최소 교정에서 긴 글은 AI가 모든 문장을 확인해 오류가 있는 문장을 먼저 찾고, 해당 문장만 고칩니다. 240자 이하의 짧은 선택 영역은 바로 교정합니다. 글을 나누어 검사하고, 완료된 부분의 제안부터 표시합니다. ‘자연스럽게’와 ‘업무용 말투’는 문장 전체를 다시 다듬으므로 더 오래 걸릴 수 있습니다.
- **로컬 AI 기본 검사**: 한글·영문 맞춤법, 띄어쓰기, 문법, 자연스러운 표현, 업무용 말투. 별도 ‘간단 규칙’ 검사 모드가 없으며 API 키·사용료가 없습니다. 설치된 모델은 앱 실행 때 미리 불러오고, 같은 글·같은 모드의 최근 결과는 메모리에서 재사용합니다.
- **단축키·진행 상태**: 기본 `Ctrl+Alt+Space`로 선택한 글을 가져옵니다. 단축키는 편의 설정에서 변경할 수 있습니다. 검사 상태·경과 시간을 확인하고 중지할 수 있습니다.
- **네이버 바로가기 제거**: 웹 검사기 링크를 앱에서 제거했습니다. 네이버 맞춤법 API 연동은 제공하지 않습니다.
- **트레이·중복 실행 방지**: X는 숨기기, 트레이 두 번 클릭은 다시 열기. EXE를 다시 실행하면 기존 창을 엽니다.
- **앱 업데이트**: 시작 시 GitHub 최신 버전을 확인합니다. ‘최신 버전 확인’에서 다운로드·검증·교체·재실행할 수 있습니다. 교체 실패 시 이전 EXE를 복구합니다. 모델과 설정은 유지됩니다.

보호할 단어 관리도 제공합니다. `Ctrl+Enter`는 검사, `Esc`는 검사 중지이며 대기 중인 검토 창에서는 닫기입니다.

## 범위와 데이터

| 엔진 | 준비 | 역할 |
| --- | --- | --- |
| **로컬 AI (기본)** | 첫 실행 자동 다운로드 | 문맥을 보고 교정·말투 변경, 한 번에 10,000자 |
| 바른 API (선택) | 본인 API 키 | 한국어 교정 + 로컬 영문 규칙, API를 선택할 때만 원문 전송 |

OpenAI API를 사용하지 않습니다. 문서 원문·검사 이력은 디스크에 저장하지 않습니다. 최근 검사 결과는 앱이 실행되는 동안 메모리에만 보관합니다. 모델은 Hugging Face/Qwen, 실행 도구는 llama.cpp의 고정 릴리스에서 내려받고 SHA-256을 검증합니다. 앱 버전 확인·업데이트에는 GitHub를 사용합니다. 바른 키는 Windows DPAPI로 암호화해 저장하며 [무료 한도](https://bareun.ai/product)는 제공자에서 확인하세요.

네이버 공식 공개 API 목록에서 일반 개발자가 발급받을 수 있는 문장 맞춤법 검사 API를 확인하지 못했습니다. 검색어 오타 변환은 문장 교정과 다른 기능입니다. [네이버 공식 API 목록](https://developers.naver.com/products/intro/plan/plan.md)

다운로드 완료와 모델의 메모리 준비 완료는 다릅니다. 앱을 켠 직후에는 준비가 끝날 때까지 기다릴 수 있습니다. 검사 시간은 글 길이·내용·모드·PC 사양에 따라 달라지고 CPU만 있는 PC에서는 더 느릴 수 있습니다. 짧은 예문 검사 시간은 긴 글의 대기 시간을 나타내지 않습니다. 빠른 맞춤법 검토에는 최소 교정을 사용하고, 문장 전체를 바꾸려는 경우 ‘자연스럽게’ 또는 ‘업무용 말투’를 선택하세요.

네이버 D2의 [「2024 네이버 통합검색의 웹 성능 리뷰」](https://d2.naver.com/helloworld/9582944)를 실제 WPF 검토 창에 클립보드로 붙여넣고 최소 교정으로 검사했습니다. Qwen3 4B·RTX 3050 Ti Laptop GPU 환경에서 매번 새 프로세스를 실행해 앱의 결과 캐시가 빈 상태로 측정했습니다.

| 입력 | 첫 구간 결과 표시 | 전체 검사 | 별도 모델 메모리 준비 |
| --- | ---: | ---: | ---: |
| 본문 중 2,152자 | 1.54초 | 2.98초 | 10.87초 |
| 본문 6,177자 | 1.60초 | 8.68초 | 11.36초 |

검사 시간에는 모델 메모리 준비·다운로드·원래 앱의 선택 영역 가져오기 시간을 포함하지 않습니다. 두 검사 모두 수정 제안은 0개였고, ‘첫 구간 결과’는 첫 수정 제안을 뜻하지 않습니다. 제안이 없다는 결과가 모든 문장의 정확성을 보장하지는 않습니다. 기존 v0.3의 같은 2,152자 글은 별도 Core 엔진 측정에서 37.05초·39.53초가 걸렸으며, 이 이전 수치는 WPF 화면 경로의 측정이 아닙니다. [측정 조건과 입력 해시](docs/performance-v0.4.0.json)

AI가 오류를 놓치거나 말투·의미를 부적절하게 바꿀 수 있으므로 제안을 확인하고 선택하세요. 긴 글에서 처음 오류 문장을 찾는 단계가 놓친 문장은 이후 교정 단계에 전달되지 않습니다. 네이버 D2 글에 오류 6개를 넣은 검사에서는 3개를 교정하고 3개를 놓쳤습니다. 제한된 예문의 결과이며 일반적인 정확도 수치가 아닙니다. 숫자·날짜·URL 보존 검사도 완전한 의미 검증은 아닙니다.

직접 쓰기는 Win32 일반 Edit 입력칸에서 원문과 선택 범위가 유지된 경우만 지원합니다. 한글·Word·브라우저·서식 문서는 수정문 복사를 이용하세요. 우클릭 메뉴 표시는 선택 영역 읽기와 별개입니다. 글을 가져오지 못하는 앱에서는 선택한 글을 직접 복사한 뒤 우클릭 메뉴의 클립보드 검사나 검토 창의 붙여넣기를 이용하세요. 우클릭 검사에서 선택 영역을 찾지 못했다고 문서 전체를 가져오지는 않습니다. 관리자 권한 앱·UAC 보안 화면 등은 Windows 권한 제한으로 지원되지 않을 수 있습니다. 키보드로 선택한 글도 단축키로 가져올 수 있습니다.

업데이트 전에는 필요한 글을 복사해 두세요. 실행 파일 폴더에 쓰기 권한이 없으면 직접 새 EXE를 다운로드해야 합니다. 실행 중인 글은 업데이트로 복원하지 않습니다.

## 개발

.NET 10 SDK와 Windows가 필요합니다.

```powershell
./scripts/build.ps1
./scripts/test-updater.ps1
dotnet run --project tests/CheckCheck.Tests -c Release
# 선택: 모델 다운로드 및 실제 로컬 추론 평가
dotnet run --project tests/CheckCheck.Tests -c Release -- --local-model
```

앱은 `--smoke-test <절대 PNG 경로>`, `--lifecycle-self-test <절대 TXT 경로>`, `--native-self-test <절대 JSON 경로>`를 지원합니다. 테스트 모드에서는 모델 자동 다운로드·사용자 설정 변경을 하지 않습니다. Native 테스트는 자체 임시 입력창만 사용하고 대화형 Windows 데스크톱의 포커스 허용이 필요합니다. GitHub Actions는 코드 푸시 시 빌드·핵심 테스트·UI/트레이·업데이트 설치 테스트를 실행하며, `v*` 태그 푸시 시 EXE·ZIP·체크섬을 릴리스에 업로드합니다.

실제 검토 창의 장문 검사 시간은 로컬 모델을 설치한 뒤 다음처럼 측정할 수 있습니다. 입력은 1,000~10,000자의 UTF-8 텍스트 파일이며, 입력·출력에 절대 경로를 사용하세요. 아래 경로는 직접 준비한 파일과 출력 폴더로 바꾸세요.

```powershell
./dist/CheckCheck.exe --benchmark-quick-file "C:\CheckCheckBench\article.txt" "C:\CheckCheckBench\result.json"
```

이 명령은 WPF 검토 창의 클립보드 붙여넣기와 설치된 로컬 AI 검사를 실행합니다. JSON 보고서에는 글자 수, 입력 해시, 모델·장치, 메모리 준비 시간, 첫 구간 결과 시간, 전체 검사 시간을 구분해 기록합니다. 검토 화면 PNG도 생성합니다. 첫 구간 결과는 수정 제안이 없는 경우도 포함하며, 우클릭 원문 가져오기 시간은 이 측정에 포함하지 않습니다. 검사에 쓴 네이버 글 원문은 저장소에 포함하지 않습니다.
