# 체크체크

Windows에서 한글·영문 문장을 교정하고, 바뀌는 부분을 확인한 뒤 원하는 수정만 반영하는 무료 데스크톱 앱입니다.

## 다운로드

**[Windows EXE 다운로드](https://github.com/youkdonghun/checkcheck/releases/latest/download/CheckCheck.exe)** · **[사용안내 포함 ZIP](https://github.com/youkdonghun/checkcheck/releases/latest/download/CheckCheck-win-x64.zip)** · [릴리스 목록](https://github.com/youkdonghun/checkcheck/releases)

Windows 10/11 x64용입니다. .NET은 별도 설치하지 않아도 됩니다. 처음 실행하면 무료 로컬 AI 모델(Qwen3 4B, 약 2.4GB)과 실행 도구를 자동으로 다운로드합니다. 진행률 확인·중지·이어받기를 지원합니다. X를 눌러도 트레이에서 다운로드와 단축키가 유지됩니다. 완전히 종료하려면 트레이 아이콘을 우클릭해 **체크체크 종료**를 누르세요.

## v0.3.0

- **로컬 AI 기본 검사**: 한글·영문 맞춤법, 띄어쓰기, 문법, 자연스러운 표현, 업무용 말투. 별도 ‘간단 규칙’ 검사 모드를 제거했습니다. API 키·사용료가 없습니다.
- **검사 대기 단축**: 설치된 모델을 앱 실행 때 미리 메모리에 불러옵니다. 같은 글을 같은 모드로 다시 검사하면 메모리에 남아 있는 최근 결과를 재사용합니다.
- **단축키 설정 개선**: 기본 `Ctrl+Alt+Space`, 다른 조합으로 변경할 수 있습니다. 설정 중 단축키가 실행되는 문제와 변경한 키 처리, 중복 실행을 보완했습니다. 충돌하면 기존 단축키를 유지합니다.
- **작은 창**: 단축키로 가져온 글을 작은 창에서 자동 검사합니다. 진행 상태·경과 시간을 확인하고 중지할 수 있습니다. 수정 항목을 체크한 뒤 복사·반영하거나 크게 볼 수 있습니다.
- **우클릭 검사 버튼**: 다른 일반 앱·사이트 위에서 우클릭하면 마우스 근처에 작은 버튼이 먼저 뜹니다. 선택 영역을 미리 읽지 못해도 버튼은 표시하며, 클릭하면 선택한 글을 가져와 검사합니다. 원래 우클릭 메뉴는 유지됩니다. 설정에서 끌 수 있고, 작은 창은 로컬 AI를 사용합니다.
- **네이버 검사기 바로가기**: 원문을 복사하고 네이버 웹 검사기를 엽니다. 열린 페이지에 붙여넣어 사용할 수 있습니다.
- **트레이·중복 실행 방지**: X는 숨기기, 트레이 두 번 클릭은 다시 열기. EXE를 다시 실행하면 기존 창을 엽니다.
- **앱 업데이트**: 시작 시 GitHub 최신 버전을 확인합니다. ‘최신 버전 확인’에서 다운로드·검증·교체·재실행할 수 있습니다. 교체 실패 시 이전 EXE를 복구합니다. 모델과 설정은 유지됩니다.

원문/수정안 비교, 하나씩 검토, 바꾸기·넘기기·되돌리기, 보호할 단어 관리도 제공합니다. `Ctrl+Enter`는 검사, `Esc`는 취소(작은 창에서는 닫기)입니다.

## 범위와 데이터

| 엔진 | 준비 | 역할 |
| --- | --- | --- |
| **로컬 AI (기본)** | 첫 실행 자동 다운로드 | 문맥을 보고 교정·말투 변경, 한 번에 3,000자 |
| 바른 API (선택) | 본인 API 키 | 한국어 교정 + 로컬 영문 규칙, API를 선택할 때만 원문 전송 |

OpenAI API를 사용하지 않습니다. 문서 원문·검사 이력은 디스크에 저장하지 않습니다. 최근 검사 결과는 앱이 실행되는 동안 메모리에만 보관합니다. 모델은 Hugging Face/Qwen, 실행 도구는 llama.cpp의 고정 릴리스에서 내려받고 SHA-256을 검증합니다. 앱 버전 확인·업데이트에는 GitHub를 사용합니다. 바른 키는 Windows DPAPI로 암호화해 저장하며 [무료 한도](https://bareun.ai/product)는 제공자에서 확인하세요.

네이버 공식 공개 API 목록에는 문장 맞춤법 검사 API가 없으며, 일반 개발자가 발급받을 수 있는 맞춤법용 API 키를 확인하지 못했습니다. 검색어 오타 변환은 문장 교정과 다른 기능입니다. 앱의 네이버 버튼은 웹 검사기 바로가기이며 API 연동이 아닙니다. 원문은 클립보드에 복사하고, 웹페이지에 직접 붙여넣습니다. [네이버 공식 API 목록](https://developers.naver.com/products/intro/plan/plan.md)

검증 PC(RTX 3050 Ti)에서는 모델을 처음 메모리에 불러오는 데 약 11~16초, 준비된 모델로 짧은 예문을 검사하는 데 약 0.60~1.55초, 540자 글을 검사하는 데 약 7.6초가 걸렸습니다. 다운로드 완료와 메모리 준비 완료는 다르며, 앱을 켠 직후에는 준비가 끝날 때까지 기다릴 수 있습니다. 글 길이·내용·PC 사양에 따라 달라지고 CPU만 있는 PC에서는 더 느릴 수 있습니다.

AI가 오류를 놓치거나 말투·의미를 부적절하게 바꿀 수 있으므로 제안을 확인하고 선택하세요. 실사용 예문에서 한글 띄어쓰기와 영문 철자·문법 교정을 확인했지만, 모든 오류를 고치지는 못했습니다. 숫자·날짜·URL 보존 검사도 완전한 의미 검증은 아닙니다.

직접 쓰기는 Win32 일반 Edit 입력칸에서 원문과 선택 범위가 유지된 경우만 지원합니다. 한글·Word·브라우저·서식 문서는 수정문 복사를 이용하세요. 우클릭 버튼 표시는 선택 영역 읽기와 별개입니다. 버튼을 눌러도 글을 가져오지 못하는 앱에서는 선택한 글을 직접 복사한 뒤 작은 창에 붙여넣으세요. 우클릭 검사에서 선택 영역을 찾지 못했다고 문서 전체를 가져오지는 않습니다. 관리자 권한 앱·UAC 보안 화면 등은 Windows 권한 제한으로 지원되지 않을 수 있습니다. 키보드로 선택한 글도 단축키로 가져올 수 있습니다.

업데이트 전에는 필요한 글을 복사해 두세요. 실행 파일 폴더에 쓰기 권한이 없으면 직접 새 EXE를 다운로드해야 합니다. 실행 중인 글은 업데이트로 복원하지 않습니다.

## 개발

.NET 10 SDK와 Windows가 필요합니다.

```powershell
./scripts/build.ps1
./scripts/test-updater.ps1
dotnet run --project tests/CheckCheck.Tests -c Release
# 선택: 모델 다운로드 및 실제 로컬 추론 평가
dotnet run --project tests/CheckCheck.Tests -c Release -- --local-model
```

앱은 `--smoke-test <절대 PNG 경로>`, `--lifecycle-self-test <절대 TXT 경로>`, `--native-self-test <절대 JSON 경로>`를 지원합니다. 테스트 모드에서는 모델 자동 다운로드·사용자 설정 변경을 하지 않습니다. Native 테스트는 자체 임시 입력창만 사용하고 대화형 Windows 데스크톱의 포커스 허용이 필요합니다. GitHub Actions는 코드 푸시 시 빌드·핵심 테스트·UI/트레이·업데이트 설치 테스트를 실행하며, `v*` 태그 푸시 시 EXE·ZIP·체크섬을 릴리스에 업로드합니다.
